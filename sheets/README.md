# 구글 시트 자동 기록

앱에 저장된 출석을 구글 시트에 자동으로 정리해요. 탭 순서는 **분기별통계 → 새가족 → 최신 연도 출석현황 → …** 이에요.

### 분기별통계 (맨 앞 탭)
- 오른쪽에 최신 분기 그래프 2개: 주별 출석 추이(예배 출석·목장모임 선), 목장별 평균 출석률(막대, 60% 미만은 빨간색). 그래프 재료는 X열부터 적혀 있어요.
- 분기마다 한 줄(최신 분기부터): 주일 수, 평균 예배 출석(공식), 평균 목장모임, 최고·최저, 방문자 합계·평균, 새가족 등록, 새가족 3회 이상 출석, 목장 명단 인원, 4주 연속 결석
- 연도별 목장 출석률(%) 표 (목장 × 1~4분기), 최근 분기 4주 연속 결석 명단
- 공식 출석 = 목자 체크(O·△)와 새가족팀 체크 중 한 곳이라도 체크한 사람. 앱의 대조 화면과 같은 계산(`report.js`)을 써요.

### 새가족 (두 번째 탭)
- 앱에서 '새가족 등록'을 한 사람만, 최근 등록부터: 등록한 날, 처음 온 날, 이름, 생년월일, 전화번호, 주소, 메모, 상태, 출석 횟수
- 출석 횟수 = 새가족팀 체크나 목자 체크(O·△)로 출석한 주일 수
- 전화번호·주소를 읽어야 해서 스크립트 주인의 구글 로그인일 때만 채워져요.

### 알림 (휴대폰 푸시, 무료)
| 언제 | 누구에게 | 스크립트 속성 |
|---|---|---|
| 새가족 등록 | 회계팀 (헌금봉투 준비) | `NEWCOMER_EMAILS`, `NEWCOMER_PUSH` |
| 주일 15:30 무렵 출석 미제출 목장 | 목자들 | `REMIND_EMAILS`, `REMIND_PUSH` |

- `_EMAILS`: (지금은 안 씀) 메일로도 받으려면 주소를 쉼표로 적고, `appsscript.json`에 `https://www.googleapis.com/auth/script.send_mail` 권한을 더해야 해요.
- `_PUSH`: **ntfy** 앱(아이폰·안드로이드 무료)의 비밀 채널 이름. 받을 사람이 ntfy 앱에서 이 이름을 '구독'하면 휴대폰에 바로 알림이 떠요.
  채널 이름을 아는 사람은 누구나 받을 수 있으니 길게 정하고, 푸시에는 이름·날짜만 넣어요(전화번호·주소 없음).
- `NTFY_TOKEN`: ntfy 무료 계정의 액세스 토큰. 구글 서버는 여럿이 함께 써서 ntfy가 '너무 많음(429)'으로 막을 수 있어요. 토큰을 넣으면 내 계정 한도(무료 하루 250건)로 보내요. ntfy.sh 로그인 → Account → Access tokens에서 만들어요.
- 비워 두면 그 방법으로는 안 보내요. 메뉴 **출석 → 알림 시험 보내기**로 확인할 수 있어요.
- 미제출 알림은 메뉴 **출석 → 주일 15:30 출석 미제출 알림 켜기**를 한 번 눌러야 켜져요(구글 예약이라 ±15분).
- 이미 알린 새가족은 `NOTIFIED_IDS`에 기록해서 다시 보내지 않아요(지우지 마세요).

### 출결버스 출석 가져오기
1. '출결버스 가져오기' 탭 **A1**에 연월(예: `2026-11`)을 적고, 그 아래에 출결버스 **출결조회** 표(번호 | 이름 | 출 | 결 | 1 … 31)를 그대로 붙여 넣어요.
2. 메뉴 **출석 → 출결버스 출석 가져오기**. 주일 출석만 새가족팀 출석 체크에 더해져요(공식 출석에 반영). 여러 번 해도 중복되지 않아요.
3. 사람은 '전체인원' 탭의 같은 번호로 찾아요(동명이인도 정확히). 못 찾은 사람은 안내 메시지에 나와요.

## 설정 (처음 한 번)
1. 출석 구글 시트에서 **확장 프로그램 → Apps Script**를 여세요.
2. 파일 두 개를 넣어요.
   - `코드.gs`(또는 기존 파일): `attendance-sheet.gs` 내용 전부
   - **+ → 스크립트**로 `report` 파일을 만들고 저장소 맨 위 `report.js` 내용 전부 (앱과 같은 계산)
3. 왼쪽 톱니바퀴 → **"편집기에서 appsscript.json 매니페스트 파일 표시"**를 켜고, `appsscript.json`을 이 폴더의 `appsscript.json` 내용으로 바꿔요.
   여기 들어 있는 `datastore` 권한 덕분에 **비밀번호 없이 스크립트 주인의 구글 계정으로 Firebase를 읽어요.**
   (스크립트 주인 = Firebase 프로젝트 주인이어야 해요)
4. 톱니바퀴 → **스크립트 속성**에 `FIREBASE_PROJECT_ID`(Firebase 웹 설정의 projectId)를 넣어요. 비밀번호는 넣지 않아요.
5. 시트로 돌아가 새로고침 → 메뉴 **출석 → 지금 업데이트**. 처음 한 번은 구글이 권한 허락을 물어봐요. 본인 계정으로 허락하면 돼요.
6. **출석 → 1시간마다 자동 업데이트 켜기**

## 교인 명단 가져오기 (한 번만)
**출석 → 교인 명단 가져오기 (전체인원 탭 → 앱)** 를 누르면 '전체인원' 탭의 명단이 앱으로 들어가요.
- 이름·출생연도·목장 힌트(학교 칸)·등록일 → 교인 명단(모두가 봄)
- 전화번호·주소·생년월일·메모 → 연락처(새가족팀만 봄). 전화번호는 맨 앞 0을 되살려 `010-1234-5678` 형식으로 바꿔요.
- 이미 앱에 있는 사람은 건드리지 않아서 여러 번 눌러도 중복되지 않아요. 그 뒤 새가족은 앱의 '새가족 등록'으로 넣어요.

## 웹 앱 배포 (앱 저장 → 시트 즉시 반영)
1. Apps Script **배포 → 새 배포 → 유형: 웹 앱**
2. 다음 사용자 인증 정보로 실행: **나**, 액세스 권한이 있는 사용자: **모든 사용자** → 배포
3. 나온 웹 앱 URL을 `index.html`의 `SHEET_SYNC_URL`에 넣어요.

'모든 사용자'여도 괜찮은 이유: 이 주소로 할 수 있는 건 "시트 새로고침"뿐이에요. 데이터를 받거나 돌려주지 않고, 명단 가져오기는 메뉴에서만 돼요.
코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 웹 앱에도 반영돼요. (주소는 그대로)

## 개인정보
'전체인원' 탭에는 **전화번호·주소**가 있어요. 시트 **공유**는 새가족팀처럼 꼭 필요한 사람만 이메일로 추가하고, "링크가 있는 모든 사용자"로 열지 마세요.
목사님·부장님은 앱의 보기 비밀번호로 대시보드를 보면 돼요. 분기 통계를 시트로 보셔야 하면 그 탭만 따로 공유하는 대신, 시트 복사본을 만들어 전화번호 탭을 지운 뒤 공유하는 게 안전해요.

## 동명이인 표시
교인 명단에 같은 이름이 둘 이상이면 앱과 시트 모두 이름 뒤에 출생연도 두 자리를 붙여 보여 줘요(예: `김가은05`). 목자가 명단에 `김가은05`처럼 적어도 바로 그 사람으로 연결돼요.
