# 구글 시트 자동 기록

앱에 저장된 출석을 구글 시트에 **연도별 탭**(`2026 출석현황`, `2027 출석현황` …)으로 나눠 월별 표로 옮겨 적어요. 최신 연도 탭이 맨 앞에 와요.

- 왼쪽: A열 목장, B열 이름 (가로로 넘겨도 고정)
- 오른쪽: 11월 표 → 빈 열 → 12월 표 … 식으로 이어짐
- **O** 목장모임까지 참석 · **△** 예배만 · **X** 결석 · 빈칸은 그 주 기록 없음
- 같은 목장 이름은 A열에서 한 칸으로 합쳐져요.
- 맨 위 3번째 줄에 날짜별 **총 참석(O+△)**이 나와요. 방문자는 빼고 세요(대시보드 숫자와 같아요).
- 그 아래 4번째 줄에 날짜별 **방문자 수** 합계가 나와요.
- 목장의 '명단 수정'에서 **방문자를 숫자로도 기록**을 켜면, 그 목장 맨 아래에 **방문자 수** 줄이 생겨요.
- **앱에서 저장하면 몇 초 안에 시트도 바뀌어요.** (아래 '웹 앱 배포' 참고) 1시간마다 자동 업데이트는 혹시 놓친 신호를 채우는 보조 역할이에요.
- 시트는 보기용이에요. 업데이트할 때마다 새로 그려지니 여기에 직접 적지 마세요.

> Firebase 연결이 끝난 뒤에 설정해야 동작해요.

## 설정 (처음 한 번)
1. 출석 구글 시트를 열고 **확장 프로그램 → Apps Script**를 누르세요.
2. 원래 있던 코드를 지우고 `attendance-sheet.gs` 내용을 전부 붙여 넣은 뒤 저장하세요.
3. 왼쪽 **톱니바퀴(프로젝트 설정) → 스크립트 속성 → 스크립트 속성 추가**에서 4개를 넣으세요.

   | 속성 | 값 |
   |---|---|
   | `FIREBASE_API_KEY` | Firebase 웹 설정의 apiKey |
   | `FIREBASE_PROJECT_ID` | Firebase 웹 설정의 projectId |
   | `VIEWER_EMAIL` | `viewer@youth.app` |
   | `VIEWER_PASSWORD` | 보기 비밀번호 |

   비밀번호는 코드가 아니라 여기에만 넣어요. 코드가 공개돼도 비밀번호는 안 보여요.
4. 시트로 돌아가 새로고침하면 위 메뉴에 **출석**이 생겨요. **출석 → 지금 업데이트**를 누르세요.
   처음 한 번은 구글이 권한 허락을 물어봐요. 본인 계정으로 허락하면 돼요.
5. **출석 → 1시간마다 자동 업데이트 켜기**를 누르면 그 뒤로는 알아서 채워져요.

## 웹 앱 배포 (앱 저장 → 시트 즉시 반영)
1. Apps Script **배포 → 새 배포 → 유형: 웹 앱**
2. 다음 사용자 인증 정보로 실행: **나**, 액세스 권한이 있는 사용자: **모든 사용자** → 배포
3. 나온 웹 앱 URL을 `index.html`의 `SHEET_SYNC_URL`에 넣어요.

'모든 사용자'여도 괜찮은 이유: 이 주소로 할 수 있는 건 "시트 새로고침"뿐이에요. 데이터를 받거나 돌려주지 않아요.
코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 웹 앱에도 반영돼요. (주소는 그대로)

## 개인정보
시트에는 교인 이름과 출석 기록이 들어가요. 시트 **공유** 설정은 꼭 필요한 사람(부장님, 새가족팀장, 목사님 등)만 이메일로 추가하고, "링크가 있는 모든 사용자"로 열지 마세요.
