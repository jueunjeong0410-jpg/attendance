# 청년부 출석 체크

교회 청년부 13개 목장의 주일 출석을 목자들이 휴대폰으로 체크하고, 부장·새가족팀장·목사님이 실시간 대시보드로 확인하는 웹앱입니다.

## 왜 만들었나
종이 출석부와 단톡방 보고로 출석을 모으면 집계에 시간이 걸리고, 새가족이 정착하는지 한눈에 보기 어려웠습니다. 목자가 제출하는 순간 전체 현황이 바로 모이도록 만들었습니다.

## 주요 기능
- **출석체크** · 목장을 고르고 이름을 누르면 O(목장모임까지 참석), 꾹 누르면 △(예배만). 방문자, 메모 입력 가능
- **명단 관리** · 목장 이름, 목자, 명단을 앱 안에서 바로 수정 (새가족 표시 지원)
- **대시보드** · 총 출석 인원과 출석률, 목장별 출석, 새가족 출석, 방문자 수. 목장을 누르면 출석자·결석자 명단 확인
- **주일별 기록** · 날짜를 넘기며 지난 주 출석 확인
- **구글 시트 기록** · 출석이 월별 표(O·△·X)로 구글 시트에 자동 정리 (`sheets/` 참고)
- **앱 설치** · 휴대폰 홈 화면에 추가하면 앱처럼 실행 (PWA)

## 개인정보 보호
- 출석 데이터는 GitHub가 아닌 Firebase에 저장되며, 이 저장소에는 개인정보가 없습니다.
- 비밀번호를 아는 교인만 볼 수 있고, 수정은 편집 비밀번호를 가진 목자만 할 수 있습니다.
- 접근 권한은 앱 화면이 아니라 Firebase 보안 규칙에서 서버 단에서 막습니다.
