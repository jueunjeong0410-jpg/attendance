# 청년부 출석 체크

교회 청년부 목장의 주일 출석을 목자들이 휴대폰으로 체크하고, 새가족팀이 현장 출석을 따로 체크해 서로 맞춰 보며, 목사님·부장님이 실시간 대시보드와 분기 보고로 확인하는 웹앱입니다.

## 왜 만들었나
종이 출석부와 단톡방 보고로 출석을 모으면 집계에 시간이 걸리고, 새가족이 정착하는지 한눈에 보기 어려웠습니다. 목자가 제출하는 순간 전체 현황이 바로 모이도록 만들었습니다.

## 권한 (비밀번호 3가지)
| 권한 | 대상 | 할 수 있는 일 |
|---|---|---|
| 보기 | 목사님·부장님 | 대시보드, 보고 |
| 목자 | 목자 | + 목장 출석 체크, 목장 명단 수정 |
| 새가족팀 | 새가족팀 | + 새가족 출석·등록, 전화번호·주소 보기, 대조, 구글 시트 |

비밀번호는 이 저장소 어디에도 적지 않습니다. Firebase 콘솔의 계정(`viewer@youth.app`, `editor@youth.app`, `newfamily@youth.app`)에만 있습니다.

## 주요 기능
- **출석체크(목자)** · 목장을 고르고 이름을 누르면 O(목장모임까지 참석), 꾹 누르면 △(예배만). 방문자, 메모 입력
- **명단 관리(목자)** · 목장 이름·목자·명단 수정. 명단 이름은 교인 명단과 연결되고, 동명이인은 목자가 골라요
- **새가족(새가족팀)** · 이름 검색으로 출석 체크, 이름을 누르면 전화번호(바로 걸기)·주소, 새가족 등록(전화번호 필수)
- **대조(새가족팀)** · 새가족팀 체크와 목자 체크를 비교해 목자 쪽 누락·새가족팀 쪽 누락·목장 없음·미제출을 나눠 보여 줘요
- **대시보드** · 공식 출석(목자 체크와 새가족팀 체크 중 한 곳이라도), 목장별 출석, 새가족·방문자, 목장별 메모
- **보고** · 분기별 평균 출석·목장모임·새가족·방문자, 주별 추이, 목장별 출석률, 4주 연속 결석
- **연도별 관리** · 해마다 목장·목원이 바뀌어도 지난 연도 목장·기록은 그대로 남고 고칠 수 없어요
- **구글 시트** · 분기별통계 탭(맨 앞) + 연도별 출석현황 탭이 자동으로 채워져요 (`sheets/` 참고)
- **앱 설치** · 휴대폰 홈 화면에 추가하면 앱처럼 실행 (PWA)

## 개인정보 보호
- 출석·교인 데이터는 GitHub가 아닌 Firebase에 저장되며, 이 저장소에는 개인정보가 없습니다. 테스트는 모두 가짜 이름으로 합니다.
- 접근 권한은 앱 화면이 아니라 Firebase 보안 규칙(`firestore.rules`)이 서버에서 막습니다.
  - 전화번호·주소·생일은 따로 저장하고(`contacts`) 새가족팀 계정만 읽을 수 있어요.
  - 적어 둔 곳 말고는 기본 거부, 지난 연도 기록 수정 불가, 앱에서 출석·교인 삭제 불가, 값의 형식·길이 검사.
- 페이지 보안 정책(CSP)으로 Firebase·구글 시트 스크립트 말고 다른 곳으로는 데이터를 보낼 수 없어요.

## 파일
- `index.html` 앱 전체 · `report.js` 출석 계산(앱과 시트 스크립트 공용) · `firestore.rules` 보안 규칙
- `sheets/` 구글 시트 스크립트 · `tests/` 자동 테스트

HTML · CSS · JavaScript (프레임워크 없음) · Firebase Firestore · Firebase Authentication · GitHub Pages · Google Apps Script
